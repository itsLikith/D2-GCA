# Acknowledgement

This application is a software implementation of the research paper:

**"DME/DME RNAV Accuracy Analysis Based on the Weighted Least Squared Algorithm"**  
by **Dai Chuan-jin, Wu De-wei, Zhao Xiu-bin, Li Xiang-jun, and Yang Chun-yan** (2015).

The design, mathematical models, algorithms, and simulation methodology implemented in this project are derived directly from the concepts and equations presented in the paper. In particular, this application implements:

- DME/DME position determination using the **Weighted Least Squares (WLS)** algorithm.
- Horizontal position estimation from multiple DME stations.
- Station geometry evaluation based on DME inclusion angles.
- Position error covariance computation.
- DME station pair selection for RNAV operations.
- Accuracy analysis using the covariance and RMS error models described in the paper.
- Simulation and validation workflows based on the paper's RNAV accuracy assessment methodology.

The objective of this project is to provide a practical software realization of the theoretical framework presented in the publication and to reproduce the DME/DME RNAV positioning and accuracy-analysis techniques described by the authors.

All credit for the underlying mathematical models, accuracy formulations, and RNAV analysis methodology belongs to the original authors of the paper.
